# ஶ்ரீ வேங்கடேஶ்வர ஸ்தோத்ரம்

## அறிமுகம்

**ஶ்ரீ வேங்கடேஶ்வர ஸ்தோத்ரம்** என்பது திருமலை ஏழுமலையான் மீது பாடப்படும் 11 ஸ்லோகங்களைக் கொண்ட ஒரு புனிதமான சமஸ்கிருத துதியாகும். இது பொதுவாக **சுப்ரபாதத்திற்குப் பிறகு** பாடப்படுகிறது.

இந்த ஸ்தோத்ரம்:
- 🙏 **பெருமாளின் அழகை** விவரிக்கிறது
- 🌸 **தேவர்களின் வணக்கத்தை** குறிப்பிடுகிறது
- 💫 **பக்தர்களின் பாவ மன்னிப்பை** கோருகிறது
- 🕉️ **சரணாகதியின் உயர்வை** போதிக்கிறது
- ✨ **ராம-கிருஷ்ண அவதாரங்களை** நினைவுகூருகிறது

### வரலாறு

இந்த ஸ்தோத்ரம் பக்தர்களால் நூற்றாண்டுகளாக பாடப்பட்டு வருகிறது. இது சுப்ரபாதத்தின் இயல்பான தொடர்ச்சியாக கருதப்படுகிறது.

## ஸ்லோகம் 1: பெருமாளின் அழகு

::align[center]{
**கமலாகுச ஸூசுக குங்குமதோ**  
**நியதாருணி தாதுல நீலதனோ ।**  
**கமலாயத லோசன லோகபதே**  
**விஜயீபவ வேங்கட ஶைலபதே ॥**
}

### தமிழ் எழுத்துருமாற்றம்

::align[center]{
கமலாகுச ஸூசுக குங்குமதோ  
நியதாருணி தாதுல நீலதனோ ।  
கமலாயத லோசன லோகபதே  
விஜயீபவ வேங்கட ஶைலபதே ॥
}

|-------------|-------------|
| கமல-குச | தாமரை மார்பு (லக்ஷ்மியின்) |
| ஸூசுக | குங்குமப்பூ |
| குங்குமத: | குங்குமத்தால் |
| நியத | நிச்சயமாக |

| லோசன | கண்கள் |
| லோக-பதே | உலகங்களின் தலைவரே |

### விளக்கம்

இந்த முதல் ஸ்லோகம் ஏழுமலையானின் **தெய்வீக அழகை** வர்ணிக்கிறது:

**உடல் அழகு:**
- 💙 **நீல நிற மேனி** - கரிய மேகம் போன்ற நிறம்
- 👄 **சிவந்த உதடுகள்** - பவளம் போன்ற சிவப்பு
- 👁️ **தாமரை கண்கள்** - அன்பும் அருளும் நிறைந்த பார்வை

**லக்ஷ்மியின் அடையாளம்:**
- 🌺 **குங்குமம்** - மார்பில் லக்ஷ்மியின் குங்கும அடையாளம்
- 🙏 **என்றும் லக்ஷ்மியுடன்** - திருமார்பில் பெரிய பிராட்டியார் வாசம்

**பிரார்த்தனை:**
பக்தர்கள் **"விஜயீபவ"** (வெற்றி அளிப்பாயாக) என்று பிரார்த்திக்கின்றனர். இது:
- ✅ பக்தர்களுக்கு வாழ்வில் வெற்றி
- ✅ துன்பங்களை வெல்லும் வலிமை
- ✅ ஆன்மீக முன்னேற்றம்

::combo[முழு பொருள்]{
லக்ஷ்மியின் குங்கும அடையாளம் கொண்ட மார்போடும், நிச்சயமாக சிவந்த உதடுகளுடனும், நீல நிற உடலுடனும், தாமரை போன்ற கண்களுடனும் விளங்கும், உலகங்களின் தலைவரே, வேங்கட மலையின் தலைவரே, எனக்கு வெற்றியை அளிப்பாயாக!
}

## ஸ்லோகம் 2: தேவர்களின் வணக்கம்

::align[center]{
**ஸசதுர்முக ஷண்முக பஞ்சமுக**  
**ப்ரமுகா கிலதைவத மௌலதிமணே ।**  
**ஶரணாகத வத்ஸல ஸாரனிதே**  
**பரிபாலய மாம் வ்ருஷ ஶைலபதே ॥**
}

### தமிழ் எழுத்துருமாற்றம்

::align[center]{
ஸசதுர்முக ஷண்முக பஞ்சமுக  
ப்ரமுகா கிலதைவத மௌலதிமணே ।  
ஶரணாகத வத்ஸல ஸாரனிதே  
பரிபாலய மாம் வ்ருஷ ஶைலபதே ॥
}

### சொல் பொருள்

| சமஸ்கிருதம் | தமிழ் பொருள் |
|-------------|-------------|
| ஸ-சதுர்முக | நான்முகனுடன் (பிரம்மா) |
| ஷண்-முக | ஆறுமுகனுடன் (முருகன்) |
| பஞ்ச-முக | ஐந்து முகத்துடன் (சிவன்) |
| ப்ரமுகா: | முன்னணியில் உள்ள |
| கில | உண்மையில் |
| தைவத | தேவர்களின் |
| மௌலி-திமணே | சிகரமணியே, உச்சியே |
| ஶரணாகத-வத்ஸல | சரணடைந்தவர்களிடம் அன்பு கொண்டவரே |
| ஸார-நிதே | சாரம் நிறைந்த கருவூலமே |
| பரிபாலய | காப்பாற்றுங்கள் |
| மாம் | என்னை |
| வ்ருஷ-ஶைல-பதே | வெங்கட மலையின் தலைவரே |

### விளக்கம்

இந்த ஸ்லோகம் **திரிமூர்த்திகளின் வணக்கத்தை** விவரிக்கிறது:

**மூன்று தேவர்கள்:**
1. 🪷 **சதுர்முக (பிரம்மா)** - படைப்புக் கடவுள், நான்கு முகங்கள்
2. 🦚 **ஷண்முக (முருகன்)** - ஆறுமுகன், ஆறு முகங்கள்
3. 🔱 **பஞ்சமுக (சிவன்)** - ஐந்து முகங்கள் கொண்ட ருத்திர வடிவம்

**பெருமாளின் உயர்வு:**
இந்த மூன்று பெரும் தேவர்களும் கூட வேங்கடேஶ்வரரை **மௌலிமணி** (தலையில் அணியும் உச்ச ரத்தினம்) என்று வணங்குகின்றனர். அதாவது:
- ✨ **விஷ்ணு எல்லா தேவர்களுக்கும் மேலானவர்**
- 🙏 **படைப்பும் காப்பும் அழிப்பும் அவரிடமிருந்து**
- 👑 **தேவர்களின் தேவர் (தேவாதிதேவ)**

**சரணாகதி:**
- 💝 **சரணாகத வத்ஸல** - சரணடைந்தோரிடம் அன்பு கொண்டவர்
- 🛡️ **பரிபாலய மாம்** - என்னைக் காப்பாற்றுங்கள்
- 🏔️ **வ்ருஷஶைலபதே** - வெங்கட மலையின் தலைவரே

இந்த ஸ்லோகம் **சரணாகதியின் சாரத்தை** கற்பிக்கிறது. மூன்று தேவர்களும் வணங்கும் பெருமாளிடம் முழு சரணடைதல் என்பது மிக உயர்ந்த பக்தியாகும்.

::combo[முழு பொருள்]{
நான்முகன் (பிரம்மா), ஆறுமுகன் (முருகன்), ஐந்து முகங்கள் கொண்ட சிவபெருமான் ஆகிய தேவர்கள் உட்பட அனைத்து தேவர்களுக்கும் சிகரமணியே, சரணடைந்தோரிடம் அன்பு கொண்டவரே, சாரம் நிறைந்த கருவூலமே, வெங்கட மலையின் தலைவரே, என்னைக் காப்பாற்றுங்கள்!
}

## ஸ்லோகம் 3: பாவ மன்னிப்பு வேண்டுதல்

::align[center]{
**அதிவேலதயா தவ துர்விஷஹை**  
**ரனு வேலக்ருதை ரபராதஶதை: ।**  
**பரிதம் த்வரிதம் வ்ருஷ ஶைலபதே**  
**பரயா க்ருபயா பரிபாஹி ஹரே ॥**
}

### தமிழ் எழுத்துருமாற்றம்

::align[center]{
அதிவேலதயா தவ துர்விஷஹை  
ரனு வேலக்ருதை ரபராதஶதை: ।  
பரிதம் த்வரிதம் வ்ருஷ ஶைலபதே  
பரயா க்ருபயா பரிபாஹி ஹரே ॥
}

### சொல் பொருள்

| சமஸ்கிருதம் | தமிழ் பொருள் |

| தவ | உன்னுடைய |
| துர்விஷஹை: | தாங்க முடியாத |
| அனுவேலம் | ஒவ்வொரு நேரமும் |
| க்ருதை: | செய்யப்பட்ட |
| அபராத-ஶதை: | நூற்றுக்கணக்கான குற்றங்கள் |
| பரிதம் | நிரம்பிய |
| த்வரிதம் | விரைவில் |
| வ்ருஷ-ஶைல-பதே | வெங்கட மலையின் தலைவரே |
| பரயா | உயர்ந்த |
| க்ருபயா | கருணையால் |
| பரிபாஹி | காப்பாற்று |
| ஹரே | ஹரியே |

### விளக்கம்

இது ஒரு **மிக உணர்வுபூர்வமான மன்னிப்பு வேண்டுதல்:**

**பாவங்களின் தன்மை:**
- ⏰ **அதிவேலதயா** - நீண்ட காலமாக
- 😔 **அபராதஶதை:** - நூற்றுக்கணக்கான குற்றங்கள்
- 🔄 **அனுவேலம்க்ருதை:** - ஒவ்வொரு கணமும் செய்யப்படும்
- 😰 **துர்விஷஹை:** - தாங்க முடியாத தன்மை கொண்ட

இந்த விவரிப்பு **பக்தனின் நேர்மையை** காட்டுகிறது. தான் செய்த பாவங்களை மறைக்காமல், அவை எத்தனை கொடியவை என்று ஒப்புக்கொள்கிறார்.

**பிரார்த்தனை:**
- 🙏 **த்வரிதம்** - விரைவில்
- 💖 **பரயா க்ருபயா** - உயர்ந்த கருணையால்
- 🛡️ **பரிபாஹி** - காப்பாற்றுங்கள்

**ஆழமான தத்துவம்:**
பக்தன் கூறுகிறார்: "என் பாவங்கள் தாங்க முடியாத அளவுக்கு நிறைந்துள்ளன. ஆனால் உன் கருணை அதை விட அதிகம். எனவே என்னை விரைவில் காப்பாற்று!"

இது **பக்தி மார்க்கத்தின் சாரம்**: நமது முயற்சி அல்ல, **பெருமாளின் கருணையே** நம்மை காப்பாற்றும்.

### விளக்கம்

**வேதங்களின் சாட்சி:**
- 📚 **அனி அகமை:** - முடிவில்லா வேதங்கள்
- 🕉️ **பர தேவதயா கதித** - மேலான தெய்வம் என்று கூறப்பட்டது

**உன்னத குணங்கள்:**

1. **உதாரம் (தாராள மனம்):**
   - 💎 மிக தாராளமாக அருளும் தன்மை
   - 🌟 கேட்பதை விட அதிகமாகத் தரும் இயல்பு

2. **தானரத (தானத்தில் ஆர்வம்):**
   - 🎁 தானம் செய்வதில் மிக்க விருப்பம்
   - 🙌 பக்தர்களுக்கு அருள், ஞானம், பக்தி அனைத்தும் தானமாக அளிப்பவர்

3. **ஜனதா (மக்கள் தரும் வள்ளல்):**
   - 🤲 எல்லோருக்கும் சமமாகத் தருபவர்
   - ❤️ பாகுபாடு இல்லாத அன்பு

**முடிவுரை:**
பக்தன் தீர்மானமாக கூறுகிறார்: **"ன பரம் கலயே"** (வேறு யாரையும் உயர்ந்தவராக நினைக்கவில்லை)

இது:
- 🎯 **ஏக பக்தி** - ஒரே தெய்வ நம்பிக்கை
- 💪 **உறுதியான நம்பிக்கை** - மாறாத பக்தி
- 🌺 **லக்ஷ்மி பதியே உயர்ந்தவர்** என்ற அசைக்க முடியாத நம்பிக்கை

::combo[முழு பொருள்]{
வேங்கட மலையில் வாழும் மிகவும் உதார மனமுடையவரே, மக்களுக்கு தானம் அளிப்பதில் என்னை விட அதிக ஆர்வம் கொண்டவரே, முடிவில்லாத வேதங்களால் மேலான தெய்வம் என்று கூறப்பட்ட, தாமரை மீது பிறந்த லக்ஷ்மியின் அன்புக்குரியவரை விட உயர்ந்த வேறு யாரையும் நான் நினைக்கவில்லை.

## ஸ்லோகம் 5: கிருஷ்ணனை விட உயர்ந்தவர் இல்லை

### தமிழ் எழுத்துருமாற்றம்

### விளக்கம்

இந்த ஸ்லோகம் **கிருஷ்ண அவதாரத்தின் மகிமையை** கொண்டாடுகிறது:

**கிருஷ்ணனின் வேணு மாதுரி:**
- 🎵 **கல வேணுரவ** - இனிமையான புல்லாங்குழல் இசை
- 💕 **அவஶ கோபவதூ** - கோபியரை வசப்படுத்திய சக்தி
- 👭 **ஶதகோடி** - நூறு கோடி கோபியர் (அளவில்லா பக்தர்கள்)

**அழகின் உச்சம்:**
- 🏹 **ஸ்மர கோடி ஸமாத்** - கோடி மன்மதர்களுக்கு சமமான அழகு
- ✨ மன்மதன் அழகுக்கு தெய்வம், ஆனால் கிருஷ்ணன் **கோடி மன்மதர்களுக்கு சமம்**
- 🌸 **பல்லவிகா** - இளம் பெண்களின் இதயத்தை கவர்ந்தவர்

**தத்துவார்த்தம்:**
இந்த ஸ்லோகம் உலகளாவிய **பிரேம பக்தியை** குறிப்பிடுகிறது:
- 💝 கோபியர்களின் கிருஷ்ண பக்தி **மிக உயர்ந்த பக்தி**
- 🎶 வேணு கானம் **பிரணவத்தின் (ஓம்) இசையை** குறிக்கிறது
- 🙏 **வசுதேவ ஸுத (வசுதேவர் மகன்)** என்று அழைப்பது அவதார நிகழ்வை நினைவூட்டுகிறது

**வேங்கடேஶ்வரர் = கிருஷ்ணர்:**
பக்தன் உறுதியாக கூறுகிறார்: "வசுதேவ ஸுதனை (கிருஷ்ணனை) விட உயர்ந்தவர் இல்லை. அவரே வேங்கடேஶ்வராக இங்கு எழுந்தருளியுள்ளார்."

::combo[முழு பொருள்]{
இனிமையான புல்லாங்குழல் இசையால் நூறு கோடி கோப மகளிரை வசப்படுத்திய, கோடிக்கணக்கான மன்மதர்களுக்கு சமமான அழகுடன், ஒவ்வொரு இளம்பெண்ணுக்கும் சுகத்தை அளித்த வசுதேவரின் புத்திரனை (கிருஷ்ணனை) விட உயர்ந்த வேறு யாரையும் நான் நினைக்கவில்லை.

## ஸ்லோகம் 7: ராமனின் திவ்ய அழகு

::align[center]{
**அவனீ தனயா கமனீய கரம்**  
**ரஜனீகர சாரு முகாம்புருஹம் ।**  
**ரஜனீசர ராஜத மௌலி ஹிரம்**  
**மஹனீய மஹம் ரகுராமமயே ॥**
}

### தமிழ் எழுத்துருமாற்றம்

::align[center]{
அவனீ தனயா கமனீய கரம்  
ரஜனீகர சாரு முகாம்புருஹம் ।  
ரஜனீசர ராஜத மௌலி ஹிரம்  
மஹனீய மஹம் ரகுராமமயே ॥
}

### சொல் பொருள்

| சமஸ்கிருதம் | தமிழ் பொருள் |
|-------------|-------------|
| அவனீ-தனயா | பூமியின் மகள் (சீதை) |
| கமனீய | இனிமையான, அழகான |
| கரம் | கரத்தை (கையை) |
| ரஜனீ-கர | சந்திரன் (இரவை உண்டாக்குவது) |
| சாரு | அழகான |
| முக-அம்புருஹம் | முக தாமரை |
| ரஜனீ-ஈசர | சந்திரனை |
| ராஜத | வெள்ளி போன்ற |
| மௌலி | தலையின் மேல், சிகரம் |
| ஹிரம் | அணிகலன், ஹாரம் |
| மஹனீய | மிகவும் மரியாதைக்குரிய |
| மஹம் | மகிமைப்படுத்துகிறேன் |
| ரகு-ராம | ரகுகுலத்தில் பிறந்த ராமனை |
| அயே | உள்ளவரை |

### விளக்கம்

இந்த ஸ்லோகம் **ராமனின் திவ்ய அழகை** கவிதை நயத்துடன் வர்ணிக்கிறது:

**சீதையுடன் ராமன்:**
- 🤝 **கமனீய கரம்** - சீதையின் அழகிய கையை பிடித்தவர்
- 👰 **அவனீ தனயா** - பூமியின் மகள் சீதை
- 💑 தெய்வீக தம்பதிகளின் அன்பு

**சந்திர ஒப்பீடுகள்:**

இந்த ஸ்லோகத்தில் **மூன்று சந்திர குறிப்புகள்** உள்ளன:

1. **முகம் = சந்திரன்**
   - 🌕 **ரஜனீகர சாரு முகாம்புருஹம்**
   - முகம் அழகான தாமரை போல
   - சந்திரன் போல குளிர்ச்சியானது

2. **சந்திரனை மிஞ்சும் அழகு:**
   - ✨ **ரஜனீசர ராஜத** - சந்திரனை விட பிரகாசம்
   - 🌙 சந்திரன் வெள்ளி போல, ராமனின் ஒளி அதை மிஞ்சுகிறது

3. **மௌலி ஹிரம்:**
   - 👑 **தலையில் அணிகலன்** - கிரீடம்
   - 💎 வென்றி வில் அலங்காரம்

**கவிதை நயம்:**
இந்த ஸ்லோகத்தில் **"ர"** எழுத்து பலமுறை வருகிறது:
- கரம், ரஜனீகர, சாரு, அம்புருஹம், ரஜனீசர, ராஜத, ஹிரம், மஹனீய, ரகுராம

இது **"ர" கார ப்ரஸ்தாவம்** எனப்படும் அலங்கார முறை. இது ராம நாமத்தின் மகிமையை வெளிப்படுத்துகிறது.

**முடிவுரை:**
- 🙏 **மஹனீய மஹம்** - மிகவும் மகிமைப்படுத்துகிறேன்
- 💖 **ரகுராம** - ரகுவம்ச ராமனே என் எல்லாம்
- ✨ சீதாராமர் வேங்கடேஶ்வரரின் மற்றொரு வடிவம்

::combo[முழு பொருள்]{
பூமியின் மகளான சீதையின் அழகிய கரத்தைப் பிடித்தவரும், சந்திரன் போல அழகான முகத் தாமரை கொண்டவரும், சந்திரனையும் வெள்ளியையும் மிஞ்சும் தலையணியை அணிந்தவருமான, மிகவும் மரியாதைக்குரிய ரகுகுல ராமனை நான் மகிமைப்படுத்துகிறேன்.
}

## ஸ்லோகம் 8: ராம-லக்ஷ்மண பக்தி

::align[center]{
**ஸுமுகம் ஸுஹ்ருதம் ஸுலபம் ஸுகதம்**  
**ஸ்வனுஜம் ச ஸுகாயம மோகஶரம் ।**  
**அபஹாய ரகூத்வய மन்யமஹம்**  
**ந கதஞ்சன கஞ்சன ஜாதுபஜே ॥**
}

### தமிழ் எழுத்துருமாற்றம்

::align[center]{
ஸுமுகம் ஸுஹ்ருதம் ஸுலபம் ஸுகதம்  
ஸ்வனுஜம் ச ஸுகாயம மோகஶரம் ।  
அபஹாய ரகூத்வய மன்யமஹம்  
ந கதஞ்சன கஞ்சன ஜாதுபஜே ॥
}

### சொல் பொருள்

| சமஸ்கிருதம் | தமிழ் பொருள் |
|-------------|-------------|
| ஸு-முகம் | நல்ல முகம் உடையவர் |
| ஸு-ஹ்ருதம் | நல்ல நண்பர் |
| ஸு-லபம் | எளிதில் அடையக்கூடிய |
| ஸுக-தம் | சுகத்தை அளிப்பவர் |
| ஸ்வ-அனுஜம் | தம்முடைய தம்பி |
| ச | மற்றும் |
| ஸு-காயம் | நல்ல உடல் உடையவர் |
| மோக-ஶரம் | மோகத்தின் அம்பு |
| அபஹாய | விட்டுவிட்டு |
| ரகூ-த்வய | இரு ரகுகுலத்தவர் (ராம-லக்ஷ்மண) |
| அன்ய | வேறு |
| மஹம் | பெரியவரை |
| ன கதஞ்சன | ஒருபோதும் எதையும் |
| கஞ்சன | கொஞ்சமும் |
| ஜாது | எப்போதும் |
| பஜே | வணங்கவில்லை |

### விளக்கம்

இந்த ஸ்லோகம் **பிரபன்னர்களின் உறுதியை** வெளிப்படுத்துகிறது:

**ராமன் பற்றிய வர்ணனை:**

ஆறு "ஸு" சொற்கள் ராமனின் ஆறு சிறப்புகளை விவரிக்கின்றன:

1. 😊 **ஸுமுகம்** - நல்ல, இனிமையான முகம்
   - எப்போதும் சிரித்த முகம்
   - பக்தர்களிடம் அன்பு காட்டும் பார்வை

2. 🤝 **ஸுஹ்ருதம்** - நல்ல நண்பர்
   - விபீஷணனுக்கு நண்பர்
   - சுக்ரீவனுக்கு உதவியவர்
   - **மித்ர பாவம்** கொண்டவர்

3. 🙏 **ஸுலபம்** - எளிதில் அடையக்கூடியவர்
   - பெரிய தவம் தேவையில்லை
   - **சரணாகதியே போதும்**
   - ஏழையும் பணக்காரரும் சமமாக அடையலாம்

4. 😌 **ஸுகதம்** - சுகத்தை அளிப்பவர்
   - ஆன்மீக சுகம்
   - உலக சுகம்
   - **மோக்ஷ சுகம்**

5. 👥 **ஸ்வனுஜம்** - தம்பியுடன் (லக்ஷ்மணன்)
   - சகோதர பாசம்
   - இணைபிரியாத உறவு

6. 💪 **ஸுகாயம்** - நல்ல உடல் அமைப்பு
   - வீர தோற்றம்
   - மோக்ஷார நிறைந்த ஸ்வரூபம்

**லக்ஷ்மணன் பற்றி:**
- 💕 **மோகஶரம்** - மோகத்தின் அம்பு போன்றவர்
- 🏹 அவரது அழகும் குணங்களும் மனதை கவரும்
- 👨‍👦 ராமனின் நிழல் போல் எப்போதும் துணையாக இருந்தவர்

**உறுதியான சபதம்:**
- 🚫 **அபஹாய** - விட்டுவிட்டு (மற்றவற்றை)
- ❌ **ந கதஞ்சன கஞ்சன ஜாது பஜே** - எப்போதும் வேறு யாரையும் கொஞ்சமும் வணங்கவில்லை
- 💯 **ரகூத்வய** - இரு ரகுகுலத்தார் (ராம-லக்ஷ்மண) மட்டுமே

**ஆழமான தத்துவம்:**
இது **அநந்ய சரணாகதி** (மற்ற எந்த சரணமும் இல்லை) என்ற கோட்பாட்டை வெளிப்படுத்துகிறது:
- ✅ ராம-லக்ஷ்மண இருவரே என் தெய்வம்
- ❌ பிற தெய்வங்களை நாடேன்
- 🙏 இது **ஏக பக்தி** (ஒன்றே குறி, ஒன்றே துணை)

::combo[முழு பொருள்]{
நல்ல முகம் உடையவரும், நல்ல நண்பரும், எளிதில் அடையக்கூடியவரும், சுகம் அளிப்பவரும், நல்ல உடல் அமைப்புடையவரும், மோகத்தின் அம்பு போன்றவருமான தம் தம்பியுடன் கூடிய இரு ரகுகுலத்தவரை (ராம-லக்ஷ்மணரை) விட்டுவிட்டு, வேறு எந்த பெரியவரையும் நான் எப்போதும் கொஞ்சமும் வணங்கவில்லை.
}

## ஸ்லோகம் 9: வேங்கடேஶ்வரரே எல்லாம்

::align[center]{
**வினா வேங்கடேஶம் ந நாதோ ந நாத:**  
**ஸதா வேங்கடேஶம் ஸ்மராமி ஸ்மராமி ।**  
**ஹரே வேங்கடேஶ ப்ரஸீத ப்ரஸீத**  
**ப்ரியம் வேங்கடேஶ ப்ரயச்ச ப்ரயச்ச ॥**
}

### தமிழ் எழுத்துருமாற்றம்

::align[center]{
வினா வேங்கடேஶம் ந நாதோ ந நாத:  
ஸதா வேங்கடேஶம் ஸ்மராமி ஸ்மராமி ।  
ஹரே வேங்கடேஶ ப்ரஸீத ப்ரஸீத  
ப்ரியம் வேங்கடேஶ ப்ரயச்ச ப்ரயச்ச ॥
}

### சொல் பொருள்

| சமஸ்கிருதம் | தமிழ் பொருள் |
|-------------|-------------|
| வினா | இல்லாமல் |
| வேங்கடேஶம் | வேங்கடேஶ்வரரை |
| ந நாத: | வேறு தலைவர் இல்லை |
| ந நாத: | வேறு தலைவர் இல்லை (வலியுறுத்தல்) |
| ஸதா | எப்போதும் |
| ஸ்மராமி ஸ்மராமி | நினைக்கிறேன் நினைக்கிறேன் (இருமுறை) |
| ஹரே | ஹரியே |
| ப்ரஸீத ப்ரஸீத | பிரசன்னமாகு பிரசன்னமாகு (இருமுறை) |
| ப்ரியம் | இனிமையானதை, விருப்பமானதை |
| ப்ரயச்ச ப்ரயச்ச | அளி அளி (இருமுறை) |

### விளக்கம்

இது **மிக முக்கியமான ஸ்லோகம்**, ஏனெனில் இது **ஏக பக்தியின் சாரத்தை** வெளிப்படுத்துகிறது:

**முதல் பாதி - உறுதி:**

**"வினா வேங்கடேஶம் ந நாதோ ந நாத:"**
- 🎯 **திரும்பத் திரும்ப உறுதி** - "ந நாத: ந நாத:" (இல்லை இல்லை)
- 💪 வேங்கடேஶ்வரர் இல்லாமல் வேறு தலைவர் இல்லை
- ✨ இது **புருஷார்த்த நிர்ணயம்** - இலக்கை உறுதிப்படுத்துதல்

**"ஸதா வேங்கடேஶம் ஸ்மராமி ஸ்மராமி"**
- 🔄 **எப்போதும் நினைத்துக் கொண்டே இருக்கிறேன்**
- 🧘 இரண்டு முறை "ஸ்மராமி" - தொடர்ச்சியான நினைவு
- 📿 இது **நாம ஸ்மரணை** - எப்போதும் பெயர் ஜபம்

**இரண்டாம் பாதி - பிரார்த்தனை:**

**"ஹரே வேங்கடேஶ ப்ரஸீத ப்ரஸீத"**
- 🙏 **ப்ரஸீத ப்ரஸீத** - பிரசன்னமாகு பிரசன்னமாகு
- 💖 இருமுறை கூறுவது **உருக்கமான வேண்டுகோளை** காட்டுகிறது
- ✨ "என் மீது தயை காட்டு, உன் அருள் முகம் காட்டு"

**"ப்ரியம் வேங்கடேஶ ப்ரயச்ச ப்ரயச்ச"**
- 🎁 **ப்ரியம்** - இனிமையானதை, விருப்பமானதை
- 🙌 **ப்ரயச்ச ப்ரயச்ச** - அளி அளி (இருமுறை)
- 💝 "நான் விரும்புவதை அல்ல, **நீ விரும்புவதையே** அளி"

**இரட்டிப்பு குறிப்புகள்:**

- ந நாத: ந நாத: (இல்லை இல்லை)

- 🙏 **சரண் சரணம்** - என்றும் உன்னிடமே சரணம்

### விளக்கம்

இது **முடிவுரை ஸ்லோகம்**, ஸ்தோத்ரத்தின் **க்ஷமாபணை** (மன்னிப்பு கோருதல்):

**பாவங்களின் தன்மை:**
- 🤷 **அஜ்ஞானினா மயா** - என் அறியாமையால்
- 😔 **தோஷான் விஹிதான்** - செய்யப்பட்ட குற்றங்கள்
- 🔢 **ஶேஷான்** - மீதமுள்ள எல்லாவற்றையும்

**முக்கிய தத்துவம்:**
பக்தன் கூறுகிறார்: "நான் **அறியாமையால்** தவறு செய்தேன்"

இதன் அர்த்தம்:
- 😇 **வேண்டுமென்றே** தவறு செய்யவில்லை
- 🌫️ **மாயையால் மறைக்கப்பட்ட** உண்மையை அறியாமல் செய்தேன்

1. 🐍 **ஶேஷஶைல** - ஆதிசேஷன் வடிவில் உள்ள மலை
   - வேங்கட மலை = ஆதிசேஷன்
   - பெருமாள் ஆதிசேஷன் மீது சயனித்திருக்கிறார்

2. 💎 **ஶிகாமணே** - சிகரமணியே
   - எல்லா தெய்வங்களிலும் உயர்ந்தவர்
   - மலைகளின் மலை, உயிர்களின் உயிர்

**இரட்டிப்பு வேண்டுகோள்:**
- 🙏 **க்ஷமஸ்வ த்வம் க்ஷமஸ்வ த்வம்** - மன்னி நீ, மன்னி நீ
- 💔 இருமுறை கூறுவது **மன்னிப்பின் அவசியத்தை** காட்டுகிறது
- 😢 பக்தனின் **வருத்தமும் தாழ்மையும்** வெளிப்படுகின்றன

**இறுதி செய்தி:**
இந்த ஸ்தோத்ரத்தின் முடிவு **மன்னிப்புடன்** நிறைவு பெறுகிறது:
- ✅ பாடிய ஸ்தோத்ரத்தில் ஏதேனும் தவறு இருந்தால் மன்னி
- ✅ வாழ்க்கையில் செய்த பாவங்களை மன்னி
- ✅ உன் கருணையே எங்களை காப்பாற்றும்

**ஶேஷஶைல ரகஸ்யம்:**
- 🐍 ஆதிசேஷன் = காலம், பிரபஞ்சம் தாங்கும் சர்ப்பம்
-  பெருமாள் ஆதிசேஷன் வடிவில் மலையாக இருக்கிறார்
- 🏔️ அந்த மலை மீது மீண்டும் பெருமாளே எழுந்தருளி இருக்கிறார்
- ♾️ இது **"தானே தன்னை ஆதரித்துக் கொள்ளுதல்"** என்ற தத்துவத்தை குறிக்கிறது

## முக்கிய கருத்துக்கள்

::tabs

### தாபம் 1: அவதாரங்கள்

இந்த ஸ்தோத்ரத்தில் குறிப்பிடப்பட்ட விஷ்ணுவின் அவதாரங்கள்:

::font[Mukta Malar Tamil]{
- **ராம** - தசரதர் மகனாக, தர்மத்தை நிலைநிறுத்த
- **கிருஷ்ண** - வசுதேவர் மகனாக, பக்தி மார்க்கம் காட்ட
- **வேங்கடேஶ்வர** - கலியுகத்தில் மலையில் நிலையாக வாசம்
}

### தாபம் 2: பக்தியின் வகைகள்

::font[Mukta Malar Tamil]{
- **சௌந்தர்ய பக்தி** - அழகை ரசித்து வணங்குதல் (ஸ்லோகம் 1, 7)
- **சரணாகதி** - முழுமையாக சரணடைதல் (ஸ்லோகம் 2, 9)
- **க்ஷமாபணை** - பாவ மன்னிப்பு வேண்டுதல் (ஸ்லோகம் 3, 11)
- **ஏக பக்தி** - ஒரே தெய்வ நம்பிக்கை (ஸ்லோகம் 4, 5, 8)
- **மனச் சேவை** - தூரத்திலிருந்தும் பக்தி (ஸ்லோகம் 10)
}

### தாபம் 3: தெய்வீக அழகு

::font[Mukta Malar Tamil]{
- **நீல மேனி** - கரிய மேக வண்ணம்
- **தாமரை கண்கள்** - அருளும் அன்பும் நிறைந்த பார்வை
- **சிவந்த உதடுகள்** - பவள சிவப்பு
- **குங்கும மார்பு** - லக்ஷ்மியின் அடையாளம்
- **சந்திர முகம்** - குளிர்ச்சியான முகம்
- **வெள்ளி ஒளி** - சந்திரனை மிஞ்சும் பிரகாசம்
}

### தாபம் 4: மலை மகிமை

::font[Mukta Malar Tamil]{
- **வேங்கட ஶைல** - வேங்கட மலை
- **வ்ருஷ ஶைல** - விருஷாசலம் (காளை மலை)
- **ஶேஷ ஶைல** - ஆதிசேஷன் வடிவில் உள்ள மலை
- **ஶிகாமணி** - மலைகளின் உச்சி, உச்ச மணி
- **திருமலை** - புனித மலை, செல்வ மலை
}

### தாபம் 5: சரணாகதி தத்துவம்

::font[Mukta Malar Tamil]{
- **அநந்ய பக்தி** - மற்ற எதையும் நாடாத பக்தி
- **ஸக்ருத் சரணாகதி** - ஒரு முறை சரணடைதல் போதும்
- **நித்ய சேவா பலன்** - என்றும் சேவிக்கும் பேறு
- **பெருமாள் கருணையே முக்கியம்** - நம் முயற்சி அல்ல
- **ஜாது ன பஜே அன்யம்** - வேறு யாரையும் வணங்கேன்
}

### தாபம் 6: பிரார்த்தனை சாரம்

இந்த ஸ்தோத்ரத்தின் பிரார்த்தனைகள்:

::font[Mukta Malar Tamil]{
- **விஜயீபவ** - வெற்றியை அளிப்பாயாக
- **பரிபாலய மாம்** - என்னைக் காப்பாற்று
- **பரிபாஹி ஹரே** - கருணையுடன் காப்பாற்று
- **ப்ரஸீத** - பிரசன்னமாகு, அருள் முகம் காட்டு
- **ப்ரயச்ச ப்ரியம்** - இனிமையானதை அளி
- **க்ஷமஸ்வ** - மன்னிப்பாயாக
}

## ஸ்தோத்ர பலன்கள்

இந்த **ஶ்ரீ வேங்கடேஶ்வர ஸ்தோத்ரத்தை** தினமும் ஓதுவதால் கிடைக்கும் பலன்கள்:

::font[Mukta Malar Tamil]{

### 1. ஆன்மீக பலன்கள்
- 🙏 **பெருமாளின் அருள்** நிச்சயம் கிடைக்கும்
- ✨ **மன அமைதியும் தெளிவும்** வரும்
- 💖 **பக்தி நெஞ்சில்** ஆழமாக வேரூன்றும்
- 🕉️ **கர்ம பலன்கள்** குறையும்

### 2. உலக பலன்கள்
- 🌟 **துன்பங்கள்** விலகும்
- 💪 **திடமான மனம்** உருவாகும்
- 🎯 **வாழ்வில் வெற்றி** கிடைக்கும்
- 🏆 **தடைகள்** அகலும்

### 3. சிறப்பு பலன்கள்
- 🏔️ **திருமலை தரிசன யோகம்** கிடைக்கும்
- 👀 **பெருமாளின் திருமுக தரிசனம்** கிடைக்கும்
- 🎁 **வேண்டியவை** அருளால் நிறைவேறும்
- ♾️ **நித்ய சேவை பலன்** கிடைக்கும்

### 4. அறிவுசார் பலன்கள்
- 📚 **வேதாந்த ஞானம்** பெருகும்
- 🧘 **மோக்ஷ மார்க்கம்** தெளிவாகும்
- 💡 **தத்துவ உணர்வு** விடியும்
- 🌅 **ஆன்மீக முன்னேற்றம்** நடக்கும்

### எப்போது ஓத வேண்டும்?

1. **காலை வேளை** - சுப்ரபாதத்திற்குப் பிறகு
2. **திருமலை தரிசனத்திற்கு முன்** - பெருமாளை காண செல்பவர்கள்
3. **சான்றிதியில்** - கோவிலில் பெருமாள் சந்நிதியில்
4. **வீட்டில்** - தினசரி பூஜையின் போது
5. **எக்காத்தஶி** - விஷ்ணு விரத தினங்களில்

### சரியான முறை

- 🛁 **சுத்தமாக** குளித்த பிறகு
- 🪷 **பூஜை செய்து** - விளக்கு, அர்ச்சனை செய்து
- 📿 **பக்தியுடன்** - மனதில் பெருமாளை தியானித்து
- 🎵 **இசையுடன்** - முடிந்தால் இசையுடன் பாடலாம்
- 🙏 **அர்த்தத்துடன்** - பொருள் புரிந்து ஓத வேண்டும்
